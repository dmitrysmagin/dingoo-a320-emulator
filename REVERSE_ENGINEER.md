# 7days.app — Reverse Engineering Analysis

## Overview

**File**: `7days.app` — Dingoo A320 executable for the game *7 Days / HellStriker*  
**Size**: 54,061,035 bytes (≈51.6 MB)  
**Platform**: Dingoo A320 (jz4730 SoC, MIPS32 little-endian)  
**Resource section at**: offset `0x150000` (52,684,779 bytes of `.spk` archive data)  

---

## 1. File Format (.app)

The `.app` format is generated by the `elf2app` tool from the official Dingoo SDK. It wraps a MIPS32 ELF binary (`.dingoo` section) into a self-contained executable with import/export tables.

| Offset | Size | Chunk | Description |
|--------|------|-------|-------------|
| `0x0000` | 32 B | **CCDL** | Magic `CCDL` + 5 config words (code offset, size, flags, build IDs) |
| `0x0020` | 32 B | **IMPT** | `IMPT` + unknown(=8) + offset + size + padding |
| `0x0040` | 32 B | **EXPT** | `EXPT` + unknown(=9) + offset + size + padding |
| `0x0060` | 32 B | **RAWD** | `RAWD` + unk0(=1) + offset + size + unk1(=0) + entry_point + origin(=0x80A00000) + prog_size |
| `0x00A0` | 2,184 B | **IMPT data** | 72 imports header + entries + string table |
| `0x0930` | 64 B | **EXPT data** | 2 exports header + entries + string table |
| `0x0970` | 1,285,344 B | **RAWD binary** | MIPS32 code + GOT/trampolines + data + strings |
| `0x13A650` | 88,495 B | Padding | 0x00 fill |
| `0x150000` | — | **Resource archive** | `.spk` format — 3,216 entries, 52 MB |

### CCDL Header Words

```
word[0] = 0x00010000  — code offset in RAWD
word[1] = 0x00020001  — code size
word[2] = 0x00000004  — flags
word[3] = 0x17120820  — build ID/version
word[4] = 0x00162319  — build ID/version
```

### RAWD Header Fields

| Field | Value | Meaning |
|-------|-------|---------|
| entry_point | `0x80AD6A20` | `dl_main()` — standard Dingoo entry point |
| origin | `0x80A00000` | Load address in RAM |
| prog_size | `0x144270` | Code size + BSS (1,327,728 B) |
| BSS end | `0x80B44270` | End of BSS section |

## 5. Resource Format (.spk)

The `.spk` archive format is used for both Dingoo and PC versions with minor differences.

### PC .spk Format

```
uint16 LE: entry count
entry[]:
  char[32]:  name (0xCD-padded, ASCII, bare filename)
  uint32 LE: data offset (relative to start of file)
data blocks follow TOC: first offset = 2 + count × 36
```

### Dingoo .spk Format

```
uint16 LE: entry count
entry[]:
  char[64]:  name (0x00-padded, ASCII, ".\subdir\filename")
  uint32 LE: data offset
data blocks follow TOC: first offset = 2 + count × 68
```

## 8. Interesting Artifacts in the Archive

- **`WARPlayer.exe`** (2,101,248 B): Win32 MFC audio renderer (waveOutWrite API), compiled with VS 7.1 (.NET 2003), project name `HellStriker`. Non-standard subsystem (16). Found in Dingoo's `audio/` — exists because the devs shipped the PC audio tool in the same resource container.
- **`[garbled].xls`** (75,776 B): OLE2 Excel 2003 spreadsheet — **HellStriker sound effect master catalog** with VBA macros (password-protected). Lists all audio assets by category (`.pcm` / `.sau`).
- **`win32.exe`** (1,462,272 B): The PC game engine. Same codebase (s3d engine, BSP renderer, script system). Subsystem = 2 (normal Windows GUI). Built from `c:\7Days\Source\win32\`.
